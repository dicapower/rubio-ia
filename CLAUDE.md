# rubio-ia

Installs a short working agreement (core + one skill) into coding agents. Go, stdlib only. Apache-2.0, DICA POWER OÜ.

## Commands

- Check everything: `go vet ./... && go test ./...`
- Windows build check: `CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build ./cmd/rubio`

## Layout

`cmd/rubio` CLI · `internal/assets` embedded core and skill · `internal/agent` where each agent keeps its files · `internal/install` setup/remove · `internal/block` marker blocks · `internal/backup` backups and restore · `internal/doctor` read-only report · `internal/migrate` removal of Gentle-AI leftovers · `internal/tokens` size estimate.

## Rules that must not break

- **The core stays small.** A test caps it at 1,000 tokens per language. Every line is sent with every request of every session; adding one costs every user.
- **No persona, no tone.** Language is a setting (`auto`, `es-ES`, `en`), never a character. `es-ES` means Spanish from Spain, no voseo.
- **Only real noah tools.** The core may name only `mem_context`, `mem_search`, `mem_get`, `mem_save`, `mem_forget`; a test checks it.
- **Never touch what is not ours.** Edit only inside `<!-- rubio-ia:... -->` blocks; a skill is ours only if it carries `assets.SkillMarker`.
- **Back up before every write, support dry runs.** Anything that changes files goes through `internal/backup`; `restore` must undo it byte for byte.
- **Migration is dry by default.** `migrate` prints a plan and needs `--yes`. It never touches `~/.gentle-ai`.
- No network, no telemetry, no cgo. There is no self-update: install through `install.sh`, Homebrew or Scoop.
- `Formula/rubio.rb` and `bucket/rubio.json` are generated by `scripts/packaging.sh`; do not edit them. `install.sh` depends on the asset names `rubio-<tag>-<os>-<arch>.tar.gz|zip` and `SHA256SUMS`: change them in both places.
- Names of other tools (Gentle-AI, Engram, Gentleman) appear only in the migration code, its tests, `doctor` and the README section on migrating.

## Style

Standard `gofmt`, small packages, errors wrapped with `%w`, tests next to the code. Comments explain why, not what. User-facing text is plain English; Spanish lives in `README.es.md`.
